## 원자료 정정과 독립 모형의 차이

기존 기록은 06:00 자동 자막의 ‘물 타입’을 화면상 불꽃 타입으로 교정했다. 이번 화면 전체를 다시 본 결과로 기록하지 않고 이전 화면 대조의 정정 이력을 보존한다.

‘가점’이라는 자연어는 선호가 늘었다는 뜻으로 쓰였으나 원 코드의 숫자는 비용이다. 분석에서는 −5처럼 방향을 명시했다. 독립 표의 20/30/15는 설명용 값이며 원작 기술별 상수를 추출한 표가 아니다. 사용 불가 후보를 집합에서 제거하는 개선 모형과 원작의 점수 처리도 따로 적었다.

한 영상에 압축과 AI가 함께 있어도 압축 방법이 AI의 전략 향상을 직접 만든다고 추론하지 않는다. 명시적 데이터와 공간 여유가 설계 가능성을 넓힌다는 설명, 구체 전투 규칙이 행동을 바꾼다는 설명, 실제 해제 속도는 별도 근거를 요구한다.

## 남은 조사

- 원작 재현을 원하면 코드 commit·ROM 판본·입력·난수 상태를 고정한다. 현재 브랜치 링크는 변할 수 있다.
- PP 0, 이미 걸린 상태, 첫 턴, 동점에서 선택 후보와 빈도를 확인한다.
- 압축 후보 비교는 동일 자작 에셋의 크기·해제 시간·최대 메모리로 수행한다. LZ4/Zstandard나 계층 상태기는 후속 조사 후보이며 이 문서에서 도입을 확정하지 않는다.
