# 동적 난이도의 흔들림과 조정 이유 — 분석

[그룹 요약](../README.md) · [상세 분석](analysis.md) · [리서치](research.md)

## 문제와 원인

피격 한 번을 실력 저하로 읽어 난도를 낮추고 다음 성공에서 곧바로 높이면 플레이어는 번갈아 쉬워지고 어려워지는 상황을 겪는다. 사망은 실력뿐 아니라 새로운 조작 학습, 실험적인 행동, 휴식 후 복귀, 고의 실패에서도 발생한다. 관측값을 곧바로 숙련도로 취급하는 것이 문제다.

레이싱에서 선두와의 격차에 따라 추격을 돕는 러버밴딩은 상태 지표가 ‘진행 격차’인 한 사례다. 사망 횟수나 소요 시간으로 전투를 조정하는 모든 DDA가 러버밴딩은 아니다.

## 제어 과정

```text
실패·소요 시간 관측 → 최근 상태 추정 → 보정 여부 판단
        ↑                                 ↓
      실제 플레이 ← 적·보상·체크포인트 파라미터 변경
```

독립 교육 모델에서 최근 실패 관측 `x_t∈{0,1}`을 평균 `m_t=(1−α)m_(t−1)+αx_t`로 부드럽게 만들 수 있다. `0<α≤1`, 초기값 `m_0∈[0,1]`로 두면 평균도 [0,1]에 머문다. α가 크면 최근 관측에 빠르게 반응하고 작으면 과거 영향이 오래 남는다. `m_(t−1)=0.2`, 한 번 실패 `x_t=1`이면 α=1에서는 m=1, α=0.1에서는 m=0.28이다. 평균화를 했다는 사실만으로 노이즈와 고의 실패가 구분되지는 않는다.

예시 정책을 ‘m>0.6이면 난도를 한 단계 낮춤, m<0.2이면 한 단계 높임, 사이에서는 유지’로 둘 수 있다. 두 경계 사이의 유지 구간은 단일 임계값 부근의 작은 변동에 따른 반복 전환을 줄일 수 있다. 다만 관측값이 양쪽 경계를 번갈아 넘으면 여전히 진동할 수 있다. 재평가 간격, 변경 후 최소 유지 시간, 한 번의 최대 변화량, 전체 상하한도 각각 역할이 다르다. 이 상수들은 상용 게임에서 추출한 값이 아니다.

## 어떤 값을 바꿀지 선택하기

| 관측 문제 | 가능한 조절 | 주의할 점 |
| --- | --- | --- |
| 정밀 조준이 어렵다 | 표적 크기·조준 보조 | 적 체력만 낮춰도 조준 장벽은 남음 |
| 반응 시간이 부족하다 | 예고 시간·공격 속도 | 퍼즐 난도까지 함께 낮출 필요 없음 |
| 반복 실패 복구가 길다 | 체크포인트·자원 복구 | 전투 자체와 복구 비용은 다른 축 |
| 선두와 격차가 크다 | 추격 보상·속도 보정 | 순위 역전의 원인과 공정성 체감 |

[Xbox 접근성 지침 108](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/108)은 난이도를 플레이어 능력과 장벽의 관계로 설명하고 개별 메커니즘 조절을 다룬다. 따라서 자동 적 체력 조절 하나를 접근성 전체로 설명하지 않는다. 플레이어가 선택한 수동 설정은 자동 추정과 분리한다.

## 해결 절차와 반례

1. 조정 대상과 관측 지표의 관계를 설명한다. 명중률이 낮아도 탄약 실험 때문이라면 조준 능력으로 단정하기 어렵다.
2. 고정 난이도를 기준으로 관측→판단→변경 로그를 남긴다. 변경 이유가 없는 상태값만 표시하지 않는다.
3. 평균화·상하한·변화율·재평가 간격을 각각 적용한다. 어느 제한 때문에 변경하지 않았는지도 구분한다.
4. 잠깐의 실수, 지속적인 학습, 휴식 복귀, 일부러 죽기라는 서로 다른 입력을 비교한다.
5. 수치 안정성과 사람의 경험을 따로 평가한다. 사망률이 낮아져도 성취감이나 주도감이 떨어질 수 있다.

너무 긴 관측 창은 필요한 도움을 늦추고, 너무 짧은 창은 오판을 늘린다. 플레이어가 보상을 얻기 위해 일부러 실패할 수 있으면 보정 자체가 최적화 대상이 된다. 경쟁 멀티플레이의 상대별 능력치 변경은 단일 플레이의 도움과 다른 정책 문제다. 현재 문서는 실제 Mario Kart·Resident Evil 버전의 숨은 상수를 복원한 것이 아니다.
