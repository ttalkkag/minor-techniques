## 분석에 추가한 모델의 성격

지수 평균식과 0.6/0.2 임계값은 관측 지연과 진동을 보여 주기 위한 독립 모형이다. XAG나 Hamlet 논문이 이 수식이나 상수를 권고했다고 인용하지 않는다. 평균화와 두 조정 경계는 반응의 흔들림을 줄이는 제안이며 플레이어 의도를 식별하거나 진동을 항상 없애는 해법은 아니다. 짧은/긴 관측 창, 변화율·최소 유지 시간·조정 이유 기록, 고의 실패 입력은 제어 정책을 비교할 조건이다.

기존 원자료는 실제 게임 장면을 설계 사례로 사용했다. 출처가 없는 ‘Mario Kart는 언제나 이 수치로 CPU를 가속한다’와 같은 재현 명세로 변환하지 않았다. 영상에 등장하는 장면과 현재 게임의 운영 규칙은 별개의 확인 대상이다.

## 남은 조사

- 조정 목표를 사망률, 진행 중단, 원하는 긴장도 중 무엇으로 둘지 구체화한다.
- 변경 이유를 이해했는지, 스스로 난도를 선택할 수 있는지 사용자 관찰로 확인한다.
- 특정 원작을 다루게 되면 해당 판본의 개발자 발표와 재현 입력을 확보한다. 지금은 교육용 제어 모형 단계다.
