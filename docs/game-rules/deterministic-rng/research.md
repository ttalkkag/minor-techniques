## 원자료의 표현 정리

‘무한 난수표’는 순차적인 출력을 설명하는 비유로 유지하고 실제로 무한 표를 메모리에 저장한다고 쓰지 않는다. 유한 상태의 결정적 PRNG는 결국 상태가 반복되어 출력도 주기적으로 반복된다. ‘컴퓨터가 난수를 전혀 만들 수 없다’는 문구도 결정적 PRNG의 한정된 설명으로 바꾼다. 외부 엔트로피를 사용하는 시스템과 구분해야 한다.

‘운빨 요소가 전혀 없다’는 제목은 조건부 결정성을 강조한다. 내부 상태를 모르는 플레이어에게는 불확실성이 있으며 게임의 확률적 결과 설계가 사라지는 것은 아니다. 최신 포켓몬 전체에서 난수 조절이 사라졌다는 주장은 직접 근거를 확보하지 못했으므로 계속 보류한다.

분리 스트림, 작은 LCG, 로컬 12턴/원격 10턴 예시는 독립 교육 모델이다. PokéRogue 저장 데이터를 조작하거나 서버 검증을 시험한 결과로 읽지 않는다.

## 남은 조사

- 고정된 코드 판본과 입력으로 매 턴 상태 해시를 비교하고 장식 호출 추가 전후를 대조한다.
- 저장 중단·기기 전환·스키마 변경에서 게임 상태와 RNG 상태를 같은 체크포인트로 복원하는지 확인한다.
- 게임 전체 결정론이 필요하면 정수 연산뿐 아니라 비동기 이벤트 순서와 물리 처리까지 범위를 정한다.
