## 두 개의 설계 축

난수를 언제 알려 주는가와 어떤 분포로 뽑는가는 서로 다른 규칙이다. 입력 무작위성은 결과를 보고 행동하고, 출력 무작위성은 행동한 뒤 결과를 받는다. 독립 추첨·천장·셔플백은 추출 분포와 기억 상태를 바꾼다. 두 축을 함께 바꾸면 결과 차이의 원인을 구분하기 어렵다. [Burgun의 설계 분류](https://keithburgun.net/good-randomness/)

## 같은 난수도 선택 순서가 달라지면 보상이 달라진다

교육용 동전에서 앞·뒤 확률은 각각 1/2다. 안전 행동은 언제나 +1, 위험 행동은 앞이면 +10, 뒤이면 −8을 준다. 결과를 모른 채 고르면 두 행동의 기대 보상은 모두 +1이다. 결과를 먼저 보고 앞일 때 위험, 뒤일 때 안전을 선택하면 기대 보상은 `(10+1)/2=5.5`다.

동전 분포는 바뀌지 않았지만 정책이 결과에 조건화되어 실제 보상 분포가 바뀐다. 따라서 ‘같은 시드와 난수 분포를 썼으니 보상도 같아야 한다’고 설명하면 틀린다. 공정한 비교에서는 정보 공개 시점, 행동 규칙, 결과 함수, 추첨 로그를 따로 기록한다. UI에 확률 숫자만 표시하는 것은 추첨 규칙 변경과 다르다.

## 독립 추첨의 긴 꼬리

성공확률 `0<p≤1`인 독립 추첨에서 첫 성공까지 횟수 N은 다음과 같다. n은 1 이상의 정수, m은 0 이상의 정수다. p=0이면 성공이 없으므로 유한한 첫 성공 기대 횟수를 정의할 수 없다.

```text
P(N=n) = (1−p)^(n−1) p
E[N] = 1/p
Var(N) = (1−p)/p²
P(N>m) = (1−p)^m
```

p=0.25면 평균은 4회, 분산은 12다. 그렇다고 4회 안에 항상 성공하는 것은 아니다. 첫 10회가 모두 실패할 확률은 `0.75^10≈5.63%`다. 이 계산은 연속한 특정 10회의 확률이며 긴 플레이 전체에서 한 번이라도 10연속 실패가 생길 확률과는 다르다.

## 실패를 제한하는 방식

| 규칙 | 필요한 기억 | 평균·최악 조건 |
| --- | --- | --- |
| 독립 추첨 | PRNG 상태 | 이전 실패가 다음 p를 바꾸지 않음 |
| K번째 시행까지 성공 보장(K≥1인 정수) | 성공 이후 실패 횟수 | N≤K. 기존 독립 추첨의 p를 유지하고 보장만 추가하면 0<p<1에서 장기 성공률 증가 |
| 셔플백 | 남은 항목과 순서 | 묶음 구성 보장, 묶음 경계 중복 가능 |
| 실패 누적 확률 | 현재 시행 번호 n | 조건부 확률 변화, 초기 상수 보정 필요 |

셔플백은 선택한 항목을 제거하고 소진 후 원래 구성으로 다시 채운다. [Godot 공식 예제](https://docs.godotengine.org/en/stable/tutorials/math/random_number_generation.html)는 이 흐름을 직접 보여 준다. `{A,B,C}` 가방이 `B,C,A`로 끝나고 다음 가방이 `A,B,C`로 시작하면 A가 연속한다. ‘같은 항목은 연속하지 않는다’는 별도 제한이다.

누적 모형을 `q_n=min(nC,1)`, `0<C≤1`로 정하고 성공 뒤 n을 1로 되돌리면 다음이 성립한다.

```text
P(N=n) = q_n × Π(k=1…n−1)(1−q_k)
E[N] = Σ(n≥0) P(N>n)
장기 성공 비율 = 1 / E[N]
```

마지막 식은 성공 뒤 동일한 규칙으로 독립적인 주기가 다시 시작하고 각 주기에 성공이 한 번 있는 모형의 장기 관계다. 유한 시행의 관측 비율이 항상 이 값과 같다는 뜻은 아니다. C=0.25를 넣으면 첫 네 번의 조건부 성공률이 0.25, 0.5, 0.75, 1이 된다. `E[N]=1+0.75+0.375+0.09375=2.21875`, 장기 성공 비율은 약 45.07%다. 표시 확률 25%를 C에 그대로 넣으면 평균을 크게 바꾼다. 목표 장기 성공률에 맞추려면 이 기대값 식을 기준으로 C를 수치적으로 찾아야 한다.

## 적용 순서와 실패 조건

1. 정보 공개 순서, 추출 규칙, 보상 크기 중 무엇을 비교하는지 고정한다.
2. p, K, 가방 구성, 누적 상수와 리셋 조건을 명시한다. 저장·복원에도 실패 횟수와 가방 잔량을 보존한다.
3. 이론 분포를 먼저 계산하고 유한 시행의 관측 평균·분산·최장 실패를 별도로 기록한다.
4. 게임 도중 규칙 변경 시 상태를 유지할지 초기화할지 정한다. 새로고침만으로 실패 이력이 지워지면 의도한 분포가 달라진다.

입력형이 모든 장르에서 우월하거나 분산이 낮을수록 더 재미있다는 결론은 이 계산에서 나오지 않는다. 보상 크기와 회복 가능성은 [전투·위험 분석](../combat-risk-reward/analysis.md), 결정적 재생은 [RNG 재현 분석](../deterministic-rng/analysis.md)으로 연결된다.
