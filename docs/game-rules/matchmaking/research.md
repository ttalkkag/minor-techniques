## 수치 정정의 이유

승·무·패에 1, 0.5, 0을 주는 순간 기대값은 각각의 확률에 이 점수를 곱한 합이다. 따라서 E=0.75가 승리 확률 75%를 뜻하려면 무승부가 없는 추가 조건이 필요하다. 본문의 0.360/0.091과 +5/−5/−15는 정의한 교육식을 재계산한 값이다.

수집 영상 설명의 서비스 링크나 파티 그림만으로 현재 운영사의 비공개 점수·파티 정책을 확인했다고 쓰지 않는다. 합성 대기열은 정책의 절충을 설명하는 자료이며 실제 사용자의 승률·대기시간을 예측한 결과가 아니다. 시간 순서에 맞춘 평가, 예측 기대점수와 관측 점수의 보정 상태, 파티별 오차는 실제 경기 자료로 아직 검증하지 않았다.

## 남은 조사

- 팀전과 파티가 필요해지면 개별 실력을 팀의 예상 결과로 변환하는 규칙을 먼저 정한다.
- 불확실성 모델을 비교할 실제 경기 데이터와 개인정보 없는 평가 기준이 필요하다.
- 경기 결과 기반 모델과 개인 성과 기반 모델의 유인 차이는 별도 조사한다. 승리에 기여하지 않는 지표 최적화를 부추길 수 있기 때문이다.
