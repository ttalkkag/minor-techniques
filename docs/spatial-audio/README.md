# 공간에 따른 소리 변화

음원·청자의 위치와 움직임, 그 사이의 벽 때문에 소리가 달라지는 문제를 다룬다. 관찰 카메라와 소리를 듣는 위치를 따로 움직이며 각 조건의 영향을 비교한다.

[전체 목차](../README.md) · [상세 분석](analysis.md) · [리서치](research.md)

## 원인별로 비교하기

| 현상 | 원인 | 해결·표현 방법 | 조절할 조건 |
| --- | --- | --- | --- |
| 멀어질수록 작아지거나 고음이 약해짐 | 거리 감쇠와 공기 흡수 | 음량과 주파수 변화를 따로 계산 | 거리·감쇠 곡선·흡수 계수 |
| 벽 끝에서 소리가 갑자기 꺼짐 | 단일 광선의 이진 차폐 | 다중 표본·재료 전달·계수 평활화 비교 | 벽 위치·음원 크기·광선 수·전달량 |
| 직접 경로가 막혀도 울림이 남음 | 다른 경로로 도달하는 반사음 | 직접음과 반사·잔향을 구분 | 주변 공간·반사 경로 |
| 순간이동 뒤 음높이가 튐 | 위치 차분을 연속 이동 속도로 해석 | 이동·속도 갱신 주기 정렬, 순간이동 시 이전 위치 재설정 | 음원·청자 속도·순간이동 |

차폐의 해결책과 도플러의 해결책은 다르다. 거리·벽·속도를 한 번에 바꾸지 않고 한 요소씩 켜서 원인을 비교한다. 다중 표본과 반사 계산에는 비용이 들고, 계수 평활화는 반응을 늦출 수 있다.

## 근거와 실험 범위

[게임 소리의 물리 영상](https://www.youtube.com/shorts/1q9srGjkpD0), Steam Audio의 직접 경로·반사 설정, Unity의 속도 갱신 규약을 참고한다. [리서치](research.md)에 각 근거의 위치와 적용 한계를 정리했다.

분석의 열린 경로 비율과 전달량 계산은 원리를 설명하는 근사이며 SDK 내부 식이나 정확한 회절 해법이 아니다. 위치·벽·속도를 각각 조절하면 서로 다른 원인을 비교할 수 있다.
