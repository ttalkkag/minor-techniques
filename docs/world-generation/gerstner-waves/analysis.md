# 수평 변위를 사용하는 파도 — 분석

[그룹 요약](../README.md) · [상세 분석](analysis.md) · [리서치](research.md)

## 원인

높이만 `sin`으로 움직이면 봉우리와 골이 대칭이다. 소수의 파동을 합치면 상공에서 파장과 방향의 반복이 드러난다. 수평 변위를 더하면 봉우리를 모을 수 있지만 변위를 너무 키우면 표면이 접혀 같은 수평 위치에 여러 표면이 생긴다.

## 작동 과정과 수식

아래는 위쪽을 y축으로 놓은 교육용 표기다. 기준 수평 좌표 `q=(u,v)`, 단위 진행 방향 `d`, 파수 `k=2π/λ`, 진폭 `A`, 각속도 `ω`, 가파름 계수 `Q`를 사용한다.

```text
θ = k(d·q) − ωt
P_horizontal(q,t) = q + Q A d cos(θ)
P_y(q,t)          = A sin(θ)
```

`Q=0`이면 높이만 변하는 사인파가 된다. `Q>0`이면 기준점 하나는 수평·수직으로 이동한다. 파동 여러 개는 각 변위를 더하되, 이를 물 입자 전체의 완전한 운동 방정식으로 해석하지 않는다. 이 설명은 [GPU Gems 1.2.3 Gerstner Waves](https://developer.nvidia.com/gpugems/gpugems/part-i-natural-effects/chapter-1-effective-water-simulation-physical-models)의 구조를 축·파수 정의를 명시해 다시 쓴 것이다.

한 방향 파동에서 수평 사상 미분은 `1−QAk sin(θ)`다. `QAk>1`이면 일부 구간에서 음수가 되어 위치 순서가 뒤집힌다. 예를 들어 `λ=10`, `A=1`, `Q=2`이면 `QAk≈1.257`이므로 접힘이 가능한 영역이다. 여러 방향 파동에서는 개별 파동만 검사하지 말고 전체 변위 미분을 본다. 모든 `Q,A,k`가 음이 아닌 이 표기에서 `Σ Q_i A_i k_i < 1`은 수평 사상의 퇴화를 피하는 보수적 조건이다. 등호 경계에서는 뾰족한 특이점이 생길 수 있으므로 여유를 둔다.

## 해결 절차

1. 기준 좌표와 변형된 좌표를 분리한다. 매 프레임 이전 결과에 변위를 누적하면 수식이 의도한 파동이 아니라 드리프트가 된다.
2. 파장·진폭·방향·위상을 소수 파동부터 조절한다. 같은 방향과 정수배 파장만 반복하면 큰 반복 무늬가 남는다.
3. 가파름은 파장과 진폭을 바꿀 때 함께 다시 평가한다. 상한을 둔 모드와 접힘을 허용한 관찰 모드는 목적을 구분한다.
4. 변형된 `P`의 두 접선 `∂P/∂u`, `∂P/∂v`로 법선을 구한다. 높이만 변하는 공식 `(-H_x,1,-H_z)`를 그대로 쓰면 수평 변위를 누락한다. 외적 순서는 y축 위쪽과 맞춘다.
5. 작은 물결은 별도 노멀 무늬로 다룬다. 메시로 표현하기 어려운 미세 파동을 정점에만 넣으면 표본 간에 봉우리가 사라지거나 반짝인다.

## 대안과 한계

| 선택 | 적합한 상황 | 해결하지 않는 부분 |
| --- | --- | --- |
| 소수 사인파 | 높이 변화와 합성을 설명 | 날카로운 봉우리, 복잡한 물 상호작용 |
| 거스너파 | 직접 제어하는 큰 파형 | 해안 쇄파, 점성, 충돌 유체 |
| 기하 + 미세 노멀 | 실루엣과 표면 세부를 따로 제어 | 미세 노멀은 실제 충돌 높이가 아님 |
| FFT 해양·얕은 물 솔버 조사 | 스펙트럼이나 지형 상호작용이 요구될 때 | 구현·성능 비교가 선행되어야 함 |

원래 좌표 q를 받아 P를 계산하는 방향과, 배의 현재 수평 위치에서 수면 높이를 찾는 역방향은 다른 문제다. 수평 변위가 있으면 단순히 현재 x,z를 q로 넣은 높이가 정확한 교차점이라는 보장은 없다. 부력이 필요해지면 역매핑과 충돌 처리까지 별도로 설계한다. 반사·굴절 역시 파형 계산이 끝난 뒤의 재질·렌더링 문제다.
