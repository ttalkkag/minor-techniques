## 독립 모델과 확인 범위

‘사용자 수정 블록을 생성 지형과 분리 저장’하는 독립 모델을 채택했다. 상세 분석은 빈 블록 수정의 존재 여부, 음수 좌표 변환, 저장 완료 전 언로드, 생성 버전 변경을 구체적인 실패 조건으로 다룬다. 원작이 정확히 같은 delta 포맷을 쓴다는 주장이 아니다.

생성 버전·시드 저장, 청크 생성 순서 변경, 파괴 블록 보존은 구현 후 확인할 조건이다. 현재 문서의 설계 설명은 청크 보존 동작을 실행하여 검증한 결과가 아니다.

## 남은 조사

- 구현 대상의 저장 방식과 종료 시 보존 범위를 정한 뒤 저장 중단·재시작을 확인한다.
- 원작 비교가 필요하면 Java/Bedrock, 게임 버전, 생성 설정을 먼저 고정하고 해당 버전 자료를 수집한다.
- 요청 취소·작업 우선순위·청크 캐시 상한은 기능 구현 때 구체화한다. 이 문서만으로 비동기 생성 스케줄러의 성능을 추정하지 않는다.
