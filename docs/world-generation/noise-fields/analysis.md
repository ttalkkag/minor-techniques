## 문제를 나누기

독립 난수로 각 높이를 정하면 이웃이 서로를 고려하지 않아 지형이 들쭉날쭉해진다. 부드러운 노이즈로 바꿔도 큰 산맥과 작은 돌기를 한 크기로만 표현하면 형태가 단조롭다. 구름에서는 이 문제에 더해 밀도 무늬를 만들고도 빛이 통과하는 모습을 계산하지 않아 납작하게 보이는 문제가 남는다.

지형 높이, 구름 밀도, 최종 조명은 다른 출력이다. 하나의 노이즈 함수가 세 과정을 완성한다고 설명하지 않는다.

## 원인과 계산 과정

2차원 gradient noise의 한 셀에서 샘플 위치를 `p=(u,v)`, 모서리를 `c00=(0,0)` 등으로 놓는다. 모서리별 gradient `gij`와 변위 `p−cij`를 내적해 `dij=gij·(p−cij)`를 구한다. 네 내적은 가중치가 없는 최종 높이가 아니다.

`f(t)=6t⁵−15t⁴+10t³`, `lerp(a,b,t)=a+t(b−a)`를 정의하면 다음과 같이 두 축으로 보간한다.

```text
bottom = lerp(d00, d10, f(u))
top    = lerp(d01, d11, f(u))
N(u,v) = lerp(bottom, top, f(v))
```

이 식은 [Perlin 2002 참조 구현](https://cs.nyu.edu/~perlin/noise/)의 보간 원리를 2차원으로 설명한 것이다. 참조 코드 자체는 3차원이며 고정 permutation을 사용한다. 위 식에 임의의 gradient 생성법을 붙였다고 원 코드와 같은 출력이 되지는 않는다.

교육용 예로 네 gradient를 모두 `(1,0)`, 샘플을 `(0.25,0.5)`로 두면 내적은 왼쪽 두 개 `0.25`, 오른쪽 두 개 `−0.75`이다. 단순 합은 `−1`이지만 보간 결과는 `0.25−f(0.25)=0.146484375`다. 방향을 샘플→모서리로 전부 뒤집으면 이 결과도 부호가 바뀐다. 일부 모서리만 뒤집는 실수와는 다르다.

Worley 계열은 다른 계산을 사용한다. 특징점 `a_i`에 대해 거리들을 정렬하고 `F1(p)=min_i distance(p,a_i)`를 얻는다. `F2`는 두 번째 거리이고 `F2−F1`은 두 최근접점이 같은 거리인 곳에서 0이 된다. 최근접점이 바뀌는 경계에서도 F1 값은 이어지지만 미분은 불연속일 수 있다. 이는 improved Perlin의 매끄러운 보간과 다른 성질이다. [Worley 원논문, nTH-CLOSEST POINT BASIS FUNCTION](https://cedric.cnam.fr/~cubaud/PROCEDURAL/worley.pdf)

## 해결 절차

1. **좌표와 재현 규칙을 고정한다.** 셀 번호는 `floor`로 구한다. 예를 들어 `x=−0.2`의 셀은 `−1`이고 내부 좌표는 `0.8`이다. 0 방향 정수 절삭을 쓰면 음수 영역에서 셀이 달라진다.
2. **기여도와 최종 값을 분리한다.** Perlin은 내적·보간 가중치·출력을, Worley는 후보점·거리·선택한 점을 각각 저장해 중간 결과를 볼 수 있게 한다.
3. **이웃 셀을 고려한다.** 경계 바로 왼쪽 샘플에서는 오른쪽 셀의 특징점이 더 가까울 수 있다. 일반적인 점 배치에 대해 고정된 이웃 개수만 검사하면 항상 충분하다고 가정하지 않는다. 셀까지의 최소 가능 거리와 현재 후보 거리로 탐색 종료를 판단한다.
4. **크기와 의미를 부여한다.** `H(p)=Σ a_i N(f_i p)`처럼 주파수·진폭을 분리하고 높이 재매핑을 적용한다. 구름은 노이즈 조합을 밀도 범위로 변환한 뒤 별도의 조명을 적용한다. 임계값·재매핑이 급격하면 원 노이즈가 부드러워도 최종 경계는 급해진다.

## 대안 선택과 실패 조건

| 요구 | 선택 기준 | 남는 문제 |
| --- | --- | --- |
| 원리 설명 | 직접 구현한 작은 2D 셀 | 특정 라이브러리와 수열 일치 여부는 별도 |
| 여러 크기의 지형 | 옥타브 합성과 높이 재매핑 | 옥타브 수만큼 평가 비용 증가, 고주파 샘플 부족 |
| 반복 무늬 완화 | 좌표를 변형하는 domain warp 후보 | 타일 주기·재현성·변형 강도 관리 |
| 먼 하늘 배경 | 텍스처나 레이어 | 구름 속 이동·시차 표현 제한 |
| 구름 내부 이동 | 3D 밀도와 볼륨 조명 | 레이마칭 샘플·그림자 비용 추가 |

높이장 `H(x,z)`는 같은 `(x,z)`에 높이 하나만 준다. 겹친 동굴은 3D 밀도처럼 다른 표현이 필요하다. 노이즈를 교체할 때 기존 저장 월드가 달라지는 문제는 [청크 저장 분석](../chunk-persistence/analysis.md)에서 다룬다. GPU 시간이 줄거나 더 자연스럽게 보이는지는 이 식만으로 확정할 수 없다.
