# 복셀 데이터에서 표면 메시 만들기 — 분석

[그룹 요약](../README.md) · [상세 분석](analysis.md) · [리서치](research.md)

## 문제와 원인

복셀은 공간의 작은 셀에 점유·재질·밀도를 저장하는 표현이다. 큐브는 그 데이터를 그리는 한 방법이다. 데이터 셀마다 독립 큐브를 만들면 서로 맞닿은 내부 면까지 생성한다. 반대로 밀도를 저장했다고 부드러운 표면이 저절로 나오지는 않는다. 표면 위치와 연결을 계산하는 별도의 메시 생성 단계가 필요하다.

## 각진 블록의 면 제거와 병합

불투명 블록의 면은 그 방향 이웃이 같은 종류의 가림을 만들지 않을 때만 생성한다. 꽉 찬 `n×n×n` 블록에서 큐브별 면은 `6n³`, 외피 면은 `6n²`개다. `n=16`이면 24,576개에서 1,536개로 줄어든다. 사각형마다 두 삼각형으로 나누는 경우의 삼각형 수도 각각 두 배다. 이는 기하 개수 계산이며 프레임 속도 16배를 뜻하지 않는다.

같은 평면 위에서 재질·방향·텍스처·조명 조건이 같은 면은 직사각형으로 병합할 수 있다. [Lysenko의 직접 구현 설명](https://0fps.net/2012/06/30/meshing-in-a-minecraft-game/)은 큐브별 생성, 내부 면 생략, greedy meshing의 메시 크기와 생성 비용을 비교한다. 블록 상태가 자주 바뀌면 더 작은 메시를 얻기 위한 병합 시간이 오히려 중요해진다.

경계 블록을 지울 때 자신의 청크만 다시 만들면 이웃 청크가 보유한 면은 이전 상태에 머문다. 이웃 청크가 아직 로드되지 않은 상황도 ‘빈 셀’과 구분한다. 미확인 이웃을 빈 공간으로 다룬 임시 면은 이웃 데이터가 도착하면 다시 평가해야 한다.

## 부드러운 표면과 Dual Contouring

밀도장 `φ(x)`의 부호 변화는 표면이 지나는 후보를 알려 준다. 원형 Dual Contouring은 격자 모서리에서의 표면 교차점 `p_i`와 단위 법선 `n_i`를 사용한다. 각 셀 정점 v는 다음 오차를 작게 만드는 위치로 정한다.

```text
E(v) = Σ [n_i · (v − p_i)]²
```

항 하나는 v가 교차점의 접평면에서 얼마나 떨어졌는지의 제곱이다. 법선이 다른 여러 평면의 제약이 만나면 모서리·꼭짓점 형태를 보존할 수 있다. 부호가 바뀌는 격자 간선 주위의 셀 정점을 연결해 면을 만든다. 이 입력과 연결 규칙을 포함해야 Dual Contouring이라는 명칭을 특정할 수 있다. [Ju 등, 2002, 2.2–2.3](https://people.eecs.berkeley.edu/~jrs/meshpapers/JuLosassoSchaeferWarren.pdf)

여러 법선이 거의 같으면 최소해가 한 점으로 잘 정해지지 않을 수 있다. 임의로 역행렬만 구하는 접근은 불안정하며 셀 밖 정점·균열·위상 변화에 대한 정책이 필요하다. 단순 밀도값은 표면까지의 거리를 보장하지 않는다. 따라서 임의 밀도를 SDF라 부르거나 거리만큼 안전하게 건너뛰는 데 그대로 쓰지 않는다.

## 구현 선택 순서

1. 요구 형상이 각진 블록인지 부드러운 표면인지 먼저 결정한다.
2. 각진 경우 이웃 점유를 읽는 노출 면 생성부터 만든다. 투명 재질끼리의 경계는 별도 규칙으로 정의한다.
3. 동일 데이터로 면 개수와 메시 재생성 비용을 비교한 뒤 병합을 추가한다. 재질·UV 경계·조명 차이를 보존한다.
4. 부드러운 경우에는 점유·밀도·거리장의 차이를 정하고 교차점·법선을 얻을 수 있는지 확인한다. 원형 DC와 다른 표면 추출법을 입력 요건으로 비교한다.
5. 논리 셀 수정 이후 메시와 필요한 충돌체가 같은 상태를 참조하도록 갱신한다. 렌더링 면이 줄었다고 충돌 계산까지 자동으로 줄었다고 간주하지 않는다.

## 실패 조건과 대가

체커보드처럼 구멍이 많은 데이터는 내부 면 제거와 병합 이득이 작다. 작은 편집마다 전체 청크를 다시 만들면 프레임 중단이 생길 수 있다. 반투명 면은 가시성과 정렬 문제가 추가된다. 부드러운 방법은 얇은 구조·격자 경계·정점 위치 안정성을 따로 확인해야 한다. 카메라 컬링은 완성된 표면의 표시 범위를 고르는 후속 단계이며 이 메시 생성 알고리즘과 동일하지 않다.
