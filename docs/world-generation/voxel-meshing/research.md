## 정정과 확정하지 않은 사실

원자료의 ‘밀도값을 부드럽게 연결한다’는 그림은 복셀 표현의 가능성을 보여 준다. 원형 DC의 정점 위치 계산과 연결 규칙을 확인하지 않고 알고리즘 명칭까지 확정하지 않는다. Donkey Kong Bananza의 구현 변형 역시 개발사의 직접 자료를 확보하지 못했으므로 계속 보류한다. 영상 설명에 외부 발표 기사 링크가 있다는 사실만으로 개발사 구현을 검증했다고 쓰지 않는다.

`6n³ → 6n²`는 완전히 찬 불투명 덩어리에 한정한 자체 계산이다. 장면의 빈 공간, 표면 복잡도, GPU 병목이 달라지므로 이 비율을 성능 향상률로 옮기지 않는다. 자료에 있는 ‘최적화’라는 말의 대상을 면 수, 재생성 시간, 표시 시간으로 분리했다.

## 남은 조사

- 재질과 조명 경계를 유지하는 병합 기준, 청크 경계 수정의 갱신 단위를 정한다.
- 매끄러운 표면이 실제 요구될 때만 원형 DC의 수치해법과 후속 SDF 방식의 입력·위상 보장을 비교한다.
- 구·평면·날카로운 모서리·얇은 벽에 대한 균열과 비매니폴드 검사는 아직 실행하지 않았다.
