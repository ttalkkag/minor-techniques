## 분석과 원자료의 관계

기존 분석에 있었던 ‘휴리스틱과 구현 조건’이라는 짧은 문장을 재개방 반례로 구체화했다. S/A/B/G 그래프는 이번에 직접 구성한 교육 예시이며 영상의 장면에서 추출한 지도가 아니다. 방향장도 화살표의 시각화와 최저 비용 선택 규칙을 분리했다. 가중 이동에서 `D(v)`만 비교하면 간선 비용을 빠뜨릴 수 있다는 점은 Bellman 최적성 식에서 도출한 설계 설명이다. 2026-09-25 교차검토에서는 비용 0 간선의 동점을 임의 선택하면 순환할 수 있는 반례를 추가하고, 역탐색의 다음 노드 기록을 유지하는 조건을 보완했다. 출처의 BFS 예제가 비용 0 반례를 직접 다룬다고 인용하지 않는다.

StarCraft의 반복 클릭이 더 빠른 이동을 만든다는 일화는 독립 구현 근거와 재현이 없어 보류한다. 단순한 플로 필드가 특정 RTS의 실제 알고리즘이라고 명명하지 않는다.

## 남은 조사

- 목표·이동 종류·지도 변경 빈도를 정한 뒤 유닛별 A*와 공유 필드의 탐색·재계산·회피 비용을 분리한다.
- 가중치, 대각선, 문 개폐, 도달 불가, 시작=목표에서 기준 비용과 비교한다.
- Recast 후보는 필요해졌을 때 대상 버전과 에이전트 반경을 고정한다. 현재는 NavMesh 도입을 확정한 문서가 아니다.
