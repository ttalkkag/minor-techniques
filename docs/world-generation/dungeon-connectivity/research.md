## 통합하면서 복구한 분석

두 영상이 모두 무작위 맵을 다루지만 첫 영상의 핵심은 방 템플릿과 진행 제약이고, Rogue 영상의 DFS는 방문 이력과 되돌아가기다. 같은 난수 알고리즘의 변형으로 합치지 않고 상위 그래프와 하위 셀 그래프라는 관계로 묶었다.

열쇠 반례와 상태 탐색은 이 프로젝트에서 설명할 독립 모델이다. 2026-09-25 교차검토에서 `(방, 열쇠 집합)`은 고유한 비소모 열쇠에 한정하고, 소모형·중복 열쇠에는 수량·획득 이력·문 개방 상태를 추가하도록 정정했다. 실제 Dead Cells·Spelunky·아이작의 저장 구조를 확인한 내용이 아니다. ‘수제 방이 있으므로 난이도가 고르다’는 인과 결론은 사용자 관찰이 없어 채택하지 않는다.

## 남은 조사

- 특정 원작 재현을 목표로 할 때 해당 게임·판본의 공식 발표나 실제 코드를 추가 확보한다.
- 실패한 시드, 원인별 실패율, 재시도 상한과 생성 시간을 기록할 구현이 필요하다.
- 위치 BFS와 열쇠·점프 상태 탐색이 다른 결과를 내는 최소 사례부터 만든다. 다수 시드를 이용한 생성 검사는 아직 실행하지 않았다.
