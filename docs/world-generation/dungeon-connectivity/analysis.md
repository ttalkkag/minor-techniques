# 던전 생성과 실제 도달 가능성 — 분석

[그룹 요약](../README.md) · [상세 분석](analysis.md) · [리서치](research.md)

## 원인: 연결된 모양과 진행 가능한 게임은 다르다

방 A에서 B로 통로가 그려져도 플레이어가 문까지 점프할 수 없으면 이동 간선이 아니다. 잠긴 문 너머에 그 문 열쇠가 있으면 방 그래프는 이어져 있어도 진행이 멈춘다. 모든 방을 독립 무작위로 고르고 마지막에 맞추려 하면 이런 모순 때문에 재시도 비용도 커진다.

무작위 생성은 좋은 후보를 고르는 과정이고, 도달성은 규칙으로 판정하는 성질이다. 시드가 있다는 사실은 진행을 보장하지 않는다.

## 상위 그래프와 방 내부를 나누기

독립 설계에서는 방을 정점, 문·통로를 간선으로 둔다. 시작→필수 방→출구의 주 경로를 먼저 구성하고 각 방에 연결 방향·크기·필수 기능을 붙인다. 그 조건에 맞는 수제 템플릿을 배치한 후 선택적 방·지름길·장식을 더한다. [Dead Cells 개발자의 설명](https://deepnight.net/tutorial/the-level-design-of-dead-cells-a-hybrid-approach/)은 고정된 월드 구조와 바이옴별 개념 그래프, 제약에 맞는 방 선택을 결합한 실제 사례다.

방 내부 미로에는 별도의 셀 그래프를 사용할 수 있다. 방문하지 않은 이웃으로 통로를 파고, 막히면 스택에서 되돌아가는 DFS가 모든 셀을 방문하면 생성 간선은 `V−1`개다. 새 방문 셀로만 간선을 추가했으므로 사이클이 없는 트리다. 그런데 방 사이 연결 단계에서 간선을 하나 더 넣으면 전체 던전에는 우회 경로가 생길 수 있다. 내부 미로의 유일 경로 성질을 전체 던전에 적용하지 않는다.

## 열쇠 반례로 보는 상태 탐색

```text
시작 S ── 방 A ── [잠긴 문 L] ── 방 B ── 출구 E
                                      └── 열쇠 K가 있는 방
```

문 개폐를 무시한 BFS는 E에 도달한다. 고유한 비소모 열쇠만 있는 모델에서 상태를 `(현재 방, 보유 열쇠 집합)`으로 바꾸면 L을 지나려면 K가 필요하고 K를 얻으려면 L을 지나야 한다는 모순이 드러난다. 위치만 방문 표시하면 같은 방을 ‘열쇠 획득 전/후’에 재방문하는 유효한 경로를 잘못 버린다.

소모형 열쇠나 같은 종류의 열쇠 여러 개를 허용하면 집합만으로는 부족하다. 예를 들어 상태를 `(현재 방, 종류별 열쇠 수, 이미 주운 열쇠 ID, 열린 문 ID)`로 확장한다. 열쇠를 처음 주울 때만 수량을 늘리고, 닫힌 문을 열 때만 수량을 줄이며, 열린 문은 다시 비용 없이 통과하도록 전이한다. 수량을 빼면 열쇠 한 개와 두 개를 혼동하고, 획득 이력을 빼면 재방문으로 열쇠를 무한 수집할 수 있으며, 열린 문 상태를 빼면 왕복할 때 열쇠를 또 소모한다. 실제 규칙에 따라 필요 없는 상태는 생략할 수 있다. 상태에는 행동의 선행 조건과 결과를 구분할 정보가 있어야 한다. [상태 공간을 이용한 전방 계획](https://artint.info/html1e/ArtInt_206.html)

플랫폼 게임에서는 높이 차·점프 능력·일방통행·낙하를 간선 조건에 추가해야 한다. 모든 방향 통로를 대칭 간선으로 두면 올라갈 수 없는 낙하 구간까지 왕복 가능한 길이 된다.

## 해결 절차

1. 필수 방, 선행 아이템, 문 방향, 이동 능력을 생성 입력으로 고정한다.
2. 상위 진행 그래프에서 필수 조건이 모순되지 않는지 확인한다.
3. 방 템플릿 후보를 연결 조건으로 줄인 뒤 선택한다. 후보가 없으면 실패 원인과 시드를 기록한다.
4. 배치 후 실제 이동·열쇠 상태 그래프를 탐색한다. 장식이 충돌을 만들 수 있으면 장식 뒤에도 확인한다.
5. 실패한 후보를 재시도할 횟수와 되돌릴 단계를 제한한다. 무한 재추첨은 ‘언젠가 성공할 것’이라는 가정에 실행 시간을 맡긴다.

## 대안 선택과 한계

| 방식 | 적합한 문제 | 한계 |
| --- | --- | --- |
| 진행 그래프 + 수제 방 | 필수 경로·레벨 의도를 유지 | 템플릿 제작 비용과 반복 노출 |
| DFS 미로 | 셀 연결과 되돌아가기를 설명 | 기본 결과는 우회 경로가 없는 트리 |
| 국소 패턴 제약/WFC | 타일 접합·외형의 일관성 | 모순 실패 가능, 열쇠 선행·전체 도달성은 추가 조건 |
| 생성 후 검사·재시도 | 작은 후보를 단순하게 탐색 | 제약이 강할수록 실패율과 지연 증가 |

[WFC 원저자 구현](https://github.com/mxgmn/WaveFunctionCollapse)은 모순으로 실행이 실패할 수 있음을 설명한다. WFC라는 이름만 추가한다고 출구 도달과 일정한 난이도가 보장되지 않는다. 연결성 검사 통과 후에도 적·함정·플레이어 능력으로 체감 난도가 달라진다. 난이도와 재미는 별도의 플레이 관찰 대상이다.
