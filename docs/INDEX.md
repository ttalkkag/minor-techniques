# 목록 페이지

[문서 목차](README.md)

게임 실험실의 첫 화면에서 어떤 현상을 관찰하고 무엇을 조절할 수 있는지 확인한 뒤, 원하는 실험으로 들어간다. 목록에서는 선택에 필요한 정보만 보여주고 원인·해결 설명과 조작은 상세 페이지에서 제공한다.

## 목록의 단위

- 항목 하나는 직접 조작할 수 있는 개별 실험이다. 물리·소리 같은 넓은 분야를 하나의 실험으로 묶지 않는다.
- 제목은 관찰할 현상을 드러내고, 짧은 설명에는 바꿔볼 조건을 적는다. 예: **벽을 통과한 총알?** — 속도와 검사 간격을 바꾸며 충돌을 비교한다.
- 분류와 관찰 방식은 태그로 표시한다. 예: `물리`, `3D 관찰`, `2D 단면`.
- 상세 페이지가 준비된 실험부터 목록에 노출한다.

## 화면 구성

상단에는 로고 없이 **게임 실험실** 제목을 두고, 본문에는 **실험 목록**과 보기 전환 버튼을 배치한다. 목록은 화면 너비에 맞춰 표시하며 길어지면 페이지를 스크롤한다.

| 보기 | 표시할 내용 | 용도 |
| --- | --- | --- |
| 썸네일 보기 — 기본 | 대표 장면·제목·짧은 설명·태그 | 어떤 현상을 다루는지 시각적으로 선택 |
| 간단 목록 보기 | 번호·제목, 우측 태그 | 여러 실험을 빠르게 훑어 선택 |

보기 전환은 **큰 네모 아이콘**과 **가로줄 아이콘**으로 표시한다. 선택한 버튼을 구분하고, 접근성 이름과 선택 상태를 제공한다. 보기만 바뀌며 실험의 순서와 상세 연결은 동일하다.

좁은 화면에서는 썸네일과 설명을 세로로 배치하고, 간단 목록의 태그는 공간이 부족하면 다음 줄로 내려 제목과 겹치지 않게 한다.

## 항목에 필요한 정보

고유 식별자·상세 주소, 표시 순서, 제목, 짧은 설명, 썸네일, 태그를 관리한다. 두 보기에서 같은 데이터를 사용하며, 목록 번호는 표시 순서에 따라 정한다. 썸네일은 실험의 대표 현상이나 비교 장면을 보여준다.

## 필수 동작

- 카드나 행을 선택하면 해당 실험 상세 페이지로 이동한다.
- 두 보기 전환과 실험 선택은 키보드로도 사용할 수 있고, 초점과 선택 상태가 보여야 한다.
- 상세 페이지에서 목록으로 돌아올 수 있어야 한다.
- 첫 구현은 목록 표시·보기 전환·상세 이동을 범위로 한다.
