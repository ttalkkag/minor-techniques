# 곡선 경로: 일정한 매개변수와 일정한 속력

[분류 요약](../README.md) · [근거와 조사](research.md)

## 곡선의 저장과 재생은 다른 문제다

네 제어점 P0~P3의 3차 베지에는 다음으로 표현된다.

```text
B(u) = (1−u)³P0 + 3(1−u)²uP1 + 3(1−u)u²P2 + u³P3
B′(0) = 3(P1−P0)
B′(1) = 3(P3−P2)
```

P0·P3는 통과하는 끝점이고 P1·P2는 형상과 접선에 영향을 주는 제어점이다. 반복 선형 보간으로도 같은 점을 구할 수 있다. SVG의 C 명령은 이런 3차 경로를 표현하지만 SVG 전체는 이동·직선·닫기·호 등 다른 명령도 갖는다. [SVG 2 Paths, 9.3](https://www.w3.org/TR/SVG2/paths.html)

실제 시간 τ에 대한 이동 속력은 `|B′(u)|×|du/dτ|`다. 같은 시간 간격에 u를 같은 양씩 늘려도 `|B′(u)|`가 변하면 속력은 달라진다. 자체 예로 한 직선 위의 P0=P1=P2=0, P3=10을 잡으면 `B(u)=10u³`이다. u=0.5에서 위치는 1.25이고 u=1에서 10이다. 경로가 직선이어도 균일 u는 균일 거리 이동이 아니다.

## 거리로 재생하기

1. 원하는 좌표계에서 곡선을 충분히 나누어 점을 샘플링한다.
2. 인접점 거리의 합으로 누적 표 `(u_i,s_i)`를 만든다. 전체 길이는 마지막 s다.
3. 재생 시간에서 원하는 거리 s를 구한다. 일정 속력이면 `s=속력×경과 시간`, 지속 시간 T>0인 출발·정지 이징이면 정규화 시간 `t=clamp(경과 시간/T,0,1)`로 `s=전체 길이×f(t)`를 구한다. 이 거리 표의 범위 안에서 이동하려면 f(t)도 [0,1] 안이어야 하며, 범위 밖 출력은 별도 끝점 정책이 필요하다.
4. 표에서 s를 끼우는 두 항목을 찾아 u를 보간한다. 두 거리 값이 같으면 길이 0 구간을 건너뛴다.
5. 해당 u로 원래 곡선 B를 평가한다. 제어점을 바꾸거나 거리 기준의 스케일을 바꾸면 표를 다시 계산한다.

이 절차는 누적 선분 길이를 이용하는 자체 근사 설계다. Godot Curve2D는 미리 계산한 점을 거리로 조회하는 실제 도구 사례이며 작은 bake_interval이 더 많은 캐시 메모리를 사용한다고 명시한다. [Curve2D](https://docs.godotengine.org/en/stable/classes/class_curve2d.html)

## 오차가 생기는 곳

굽은 곡선을 드문 점의 직선으로 잇기 때문에 누적 길이는 근사다. 표의 해상도와 역조회 보간에도 오차가 있다. 너무 거친 표는 일정 거리 모드에서도 속도 변화가 남는다. 제어점 전체가 같으면 총길이 0이므로 정규화할 길이가 없다. 그대로 한 점에 머무르게 하는 편이 명확하다.

거리 기준을 로컬 좌표로 잡은 뒤 가로만 두 배 확대하면 세계 거리의 비율이 구간마다 달라질 수 있다. 화면상 일정 속도를 원하는 UI와 세계상 일정 속도를 원하는 이동체는 측정 좌표계를 다르게 정해야 한다.

## 선택 조건

교육 모드에서는 반복 보간선을 보여 주면 제어점의 의미가 드러난다. 실제 이동에서는 경로 형상과 시간 곡선을 분리하면 속도 변화의 원인이 명확해진다. 매 순간 경로가 바뀌는 경우에는 캐시 재작성 비용이 커질 수 있어 필요한 오차에 맞게 해상도를 고른다. 두 경로를 연결할 때 위치가 같다는 것만으로 진행 방향·속도가 이어지는 것은 아니므로 끝점 접선과 재생 속력도 확인한다.
