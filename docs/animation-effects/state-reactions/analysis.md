# 상태 반응: 불·물·물체의 조합 규칙

[분류 요약](../README.md) · [근거와 조사](research.md)

## 조합이 늘 때 예외가 폭증하는 원인

‘첫 번째 나무에 첫 번째 불이 닿으면’처럼 개별 객체 쌍마다 사건을 만들면 새 나무와 불을 추가할 때 비슷한 코드를 늘려야 한다. 물리 접촉이 발생했다는 사실과 불붙음·젖음 상태가 바뀌는 규칙도 섞이기 쉽다. 같은 틱에 물과 불이 닿으면 처리 순서에 따라 결과가 달라져 화면과 이벤트 로그가 어긋날 수 있다.

물리는 위치·속도·접촉을 제공하고 상태 반응은 어떤 조건에서 무엇이 바뀌는지 결정하게 나눈다. 모든 현실 물성을 넣기보다 실험이 설명할 속성만 둔다. 예를 들어 물체의 가연성, 젖음, 불붙음 세 상태만으로도 점화와 소화의 순서를 설명할 수 있다. 이는 실제 분자 화학이나 젤다 내부 자료구조의 복원은 아니다.

## 작은 규칙 표로 시작한다

아래는 **자체 모형의 정책 예시**다. 원작 규칙을 전사한 표가 아니다.

| 입력 사건 | 조건 | 상태 변화 | 후속 사건 |
|---|---|---|---|
| 물 접촉 | 대상 존재 | 젖음=true, 불붙음=false | 이미 붙어 있었다면 소화 알림 |
| 불 접촉 | 가연성=true, 젖음=false | 불붙음=true | 최초 전환에서 점화 알림 |
| 불붙은 물체의 주변 접촉 | 전파 허용 | 다음 틱의 불 접촉 후보 생성 | 같은 대상·틱의 중복 합침 |
| 건조 시간 경과 | 자체 규칙의 시간 조건 | 젖음=false | 없음 |

연속 접촉에서 매 틱 점화 효과가 중복 생성되지 않으려면 ‘불이 닿았다’와 ‘불붙음 상태로 바뀌었다’를 구분한다. 이미 불붙은 물체에 다시 불이 닿았다는 이유만으로 최초 점화 이벤트를 반복하지 않는다.

## 동시 반응을 처리하는 절차

1. 이번 틱의 물리 접촉을 수집하고 유효한 대상 ID를 확정한다.
2. 물·불 같은 반응 후보를 종류별로 모은다. 접촉을 수집하는 도중 즉시 다른 물체를 삭제하거나 새 전파를 무한 실행하지 않는다.
3. 이 자체 예에서는 소화·젖음 처리를 먼저 적용하고 그 결과에 점화 조건을 평가한다. 그러면 같은 틱의 물과 불이 나무에 닿으면 젖은 상태가 우선한다.
4. 상태가 실제로 바뀐 사건만 표시·소리·로그로 전달한다. 전파 사건은 다음 틱으로 넘기고 중복을 합친다.
5. 다음 틱 시작 전 삭제된 대상과 큐의 참조를 정리한다. 작업량 상한을 둔다면 넘친 사건을 미룰지 버릴지 명시한다. 상한이 물리적 결과를 바꿀 수 있기 때문이다.

소화를 먼저 하는 것은 가능한 게임 규칙 하나다. 모든 결과를 이전 상태에서 동시에 계산하는 방법도 가능하지만 충돌하는 상태 변경의 결합 규칙이 필요하다. 처리 순서를 숨기는 것보다 선택을 드러내는 것이 핵심이다.

## 공통 규칙이 모든 조율을 없애지는 않는다

Nintendo 개발자는 능력과 반응하는 세계의 조합을 설명하면서 후속작 물체 결합의 많은 경우를 디자이너·프로그래머가 조율했다고 말한다. 공통 규칙이 다양한 사건을 만들 수 있어도 개별 조합의 외형·판정·피드백 조정은 남는다. [Nintendo 2023 개발자 인터뷰 Part 4](https://www.nintendo.com/us/whatsnew/ask-the-developer-vol-9-the-legend-of-zelda-tears-of-the-kingdom-part-4/)

2D 물체 배치와 이벤트 순서 표시로 먼저 설명할 수 있다. 불과 물을 동시에 놓기, 이미 타는 나무에 다시 불 적용, 원형 배치의 반복 전파, 삭제 직후 사건을 반례로 사용한다. 같은 초기 상태·입력·처리 순서·난수 상태에서 결과가 일치하는지는 구현 뒤 확인할 항목이다. 이 작은 문제를 설명하기 위해 범용 엔진이나 ECS가 반드시 필요하지는 않다.
