## 1차 자료의 판단 근거

[Triforce% 제작팀 FAQ](https://gettriforce.link/faq.html)의 Project, Lore, Data, TASBot 항목은 트라이포스 장면이 팀의 제작물이며 컨트롤러 입력으로 주입됐다고 설명한다. 행사에는 미국판 OoT 1.0 원본 카트리지를 사용했고, N64의 RGB 출력 개조는 게임 내용 변경과 다르다고 명시한다. 개발용 shortcut·romhack ROM은 행사에 사용하지 않았다고 구분한다. 개조하지 않은 카트리지로 실행했다는 설명은 모든 장면이 원래 ROM에 저장되어 있었다거나 외부 입력 장치를 쓰지 않았다는 뜻이 아니다. 이 자료는 제작팀의 구현 설명이라는 1차 근거이며 우리 환경에서 콘솔 실행을 재현한 증거는 아니다.

## 채택·제외 판단

남길 내용은 컨트롤러 입력에 의한 데이터 기록, 잘못된 실행 위치 이동, 그 결과의 게임 화면 변화다. 데이터 덮어쓰기와 제어 흐름 이동은 각각 필요한 조건으로 구분한다. 카트리지가 순정이면 모든 장면이 원래 저장돼 있었다는 추론은 제외한다.

분석 문서의 작은 명령·메모리 모형과 쓰기 범위·분기 검사 전환은 이 관계를 설명하기 위한 설계다. 원작의 정확한 메모리 주소·입력열·실기기 실행이 검증되지 않았으므로 실제 취약점 재현이나 원작 패치로 표시하지 않는다.
