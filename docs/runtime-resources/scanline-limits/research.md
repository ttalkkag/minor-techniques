# 스캔라인 제한의 영상 근거와 확인 범위

[상세 분석](analysis.md) · [그룹 요약](../README.md)

`retro-graphics`의 기존 2026-09-23 판정은 `qualified`다. 2026-09-25 원자료를 읽고 줄별 제한을 배경 데이터 재사용과 분리했다. 하드웨어 출처의 본문 확인 여부는 아래 접근 이력에 구분한다.

아래 2026-09-25 NESdev 열람 실패는 작성 단계의 기록이다. 이어진 교차검토에서는 8/9 표시 비율이 위치와 후보 집합을 고정한 순환 모델의 결과임을 명시하고 계산을 다시 확인했다. 새로운 하드웨어 명세를 검증한 것은 아니다.

## 수집 범위와 공개 영상의 쟁점

수집 ID는 `retro-graphics`다. [고전 그래픽 영상](https://www.youtube.com/watch?v=keREBAhYErY)의 근거는 관련 자막과 과거 대표 화면 대조 범위이며 이번 전체 재생 결과가 아니다. 아래 표는 그 구간의 주장과 적용 범위를 공개 영상 시각으로 연결한다.

## 하드웨어 자료의 접근 이력

| 문서 | 기존 기록 | 2026-09-25 처리 |
| --- | --- | --- |
| [NESdev PPU sprite priority](https://www.nesdev.org/wiki/PPU_sprite_priority) | 2026-09-23 검색 결과의 앞 8개 설명만 확인, 본문 403 | 열람 시 Internal Error. 본문 확인 실패 유지 |
| [PPU programmer reference](https://www.nesdev.org/wiki/PPU_programmer_reference) | 2026-09-22 조사 기록이 OAM 64개와 네임테이블을 대조했다고 기록 | 기존 노트의 참고 위치로 보존. 이번 직접 본문 검증으로 세지 않음 |
| [PPU rendering](https://www.nesdev.org/wiki/PPU_rendering) | 2026-09-22 조사 기록의 스캔라인 8개·순환 설명 참고 | 사이클 단위 동작 확정에 사용하지 않음 |

2026-09-26 재검색·본문 열람에서도 NESdev 위키와 개발자 포럼은 403 또는 Internal Error로 열리지 않았다. 보조 대조로 [Mesen 2 개발자의 NES PPU 구현](https://github.com/SourMesen/Mesen2/blob/b9fa69ddc6d0a331fb103fdb5eef6904305703c2/Core/NES/NesPpu.cpp)을 읽었다. `ProcessSpriteEvaluation()`의 높이 범위 검사와 32바이트 보조 OAM, 4바이트씩 복사하는 경로가 8후보 선택 모델과 맞는다. `LoadExtraSprites()`의 한도 제거 옵션은 에뮬레이터 확장이므로 원 하드웨어 기능으로 설명하지 않는다. 이 리비전의 소스는 2026-06-04 커밋 기준이며, 원작 실기기 측정이나 Nintendo 명세를 대신하지 않는다.

NESdev는 하드웨어 연구 자료이며 Nintendo 공식 매뉴얼은 아니다. 접근 실패를 다른 구현의 확인으로 해소했다고 보지 않으며 정밀 사양의 미확인 범위는 유지한다. 이 문서의 집합·순서 계산은 직접 정의한 모형이므로 접근하지 못한 NESdev 본문에 근거한 구현이라고 쓰지 않는다.

## 채택·정정·보류

- **채택:** 총객체 수와 한 줄에 몰린 후보 수를 분리한다. 같은 총개수라도 높이 배치에 따라 제한에 걸리는 줄이 달라진다.
- **정정 유지:** 깜박임 분산은 하드웨어가 자동으로 공평하게 고르는 기능이라는 뜻이 아니다. 소프트웨어가 선택 순서를 바꾼다는 모델로 설명한다.
- **구체화:** 한 캐릭터가 여러 조각으로 표현될 수 있어 게임 객체 개수와 표시 후보 개수를 분리했다. 이는 자체 도식의 데이터 모델이며 특정 원작의 조각 수는 제시하지 않았다.
- **보류:** 정확한 OAM 평가 타이밍, 8×8·8×16 모드별 차이, 투명 후보·화면 밖 후보·오버플로 동작, 개별 게임의 순환 코드.

분석의 9객체/8슬롯/9프레임 예시는 순환 목록의 산술이다. 실제 콘솔의 깜박임 빈도나 공정성을 측정한 값이 아니다. 원자료의 9번째 객체 배치 과제와 프레임별 선택 기록 과제는 아직 실행하지 않았다.

같은 영상의 팔레트·타일·메모리 비교는 [인덱스 재사용 리서치](../indexed-reuse/research.md)에서 다룬다. DS의 양 화면 3D 출력과 Mode 7을 이 스캔라인 후보 제한으로 설명하지 않는다.
