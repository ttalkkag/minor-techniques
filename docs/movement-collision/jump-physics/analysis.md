# 점프 궤적과 시간 간격

[그룹 요약](../README.md) · [출처와 판단](research.md)

통합 원자료: `jump-physics`, `mario-controls`. 아래 수치는 원작 마리오의 복원값이 아닌 계산 예다.

## 문제를 세 가지로 나눈다

화면이 끊기는 현상, 점프 높이가 달라지는 현상, 버튼을 놓아도 높이 뛰는 현상은 원인이 다르다. 첫째는 표시 시점, 둘째는 운동 규칙·적분 간격·입력 시점, 셋째는 가변 점프 설계와 관련된다. 하나의 FPS 슬라이더로 전부 바꾸면 무엇이 개선됐는지 알 수 없다.

매 화면마다 `y += 1`이면 30 FPS에서 초당 30단위, 120 FPS에서는 120단위 이동한다. `v × Δt`를 더하면 이 문제는 줄어들지만, 충돌과 가속도까지 포함한 이산 계산의 결과가 모든 간격에서 같아지지는 않는다.

## 운동 규칙과 적분법

위쪽을 양수로 하고 일정 가속도 `a < 0`, 초기 속도 `v0 > 0`를 가정한다. 충돌과 버튼 해제가 없으면 기준 궤적은 `y(t)=y0+v0t+at²/2`다. 최고점 시각은 `-v0/a`, 상승 높이는 `-v0²/(2a)`다.

고정 간격 `h`에서 두 계산법은 다음과 다르다.

```text
명시적 Euler:   y_next = y + v × h
                 v_next = v + a × h
반암시적 Euler: v_next = v + a × h
                 y_next = y + v_next × h
```

예를 들어 `y0=0`, `v0=10 m/s`, `a=-20 m/s²`, `h=0.1 s`이면 첫 스텝의 해석적 위치는 `0.9 m`, 명시적 결과는 `1.0 m`, 반암시적 결과는 `0.8 m`다. 영상 끝 식은 새 속도로 위치를 갱신하므로 반암시적 형태로 읽는다.

일정 가속도에서 `t=n h`일 때 반암시적 위치 오차는 `a t h / 2`다. 중력·입력·충돌 조건이 중간에 바뀌면 이 식을 전체 궤적에 그대로 적용할 수 없다. 작은 간격의 장점은 이런 수치 오차를 줄이는 것이며, 실제 중력을 바꾸는 것과 구분한다.

## 조작감의 설계값

상승과 하강 가속도를 다르게 두면 같은 초기 속도에서도 체공시간이 달라진다. 이는 의도적인 운동 모델이다. 상승 중 버튼 해제 시 `v = min(v, v_cut)`으로 제한하거나 상승 가속도를 바꾸는 방법을 선택할 수 있다. `v_cut ≥ 0`으로 정하고 하강 중에는 속도 절단을 적용하지 않아 낙하가 갑자기 느려지지 않게 한다.

수평 이동은 입력 방향 가속, 무입력 감속, 반대 입력 제동, 공중 제어량을 나눈다. 무입력 감속은 매 스텝 속도를 0 쪽으로 제한해 감속만으로 방향이 뒤집히지 않게 한다. 예를 들어 속력 `6 m/s`, 일정 감속도 `12 m/s²`의 연속 모델에서는 정지까지 `0.5 s`, 이동 거리 `1.5 m`다. 이산 구현은 해당 기준과 오차를 비교한다.

이 값들은 함께 결과를 바꾼다. 점프 높이가 같아도 수평 가속·체공시간이 다르면 건널 수 있는 간격이 달라진다. 먼저 한 값만 바꾼 뒤 조합을 비교해야 한다.

## 갱신 순서와 표시

1. 입력 발생을 기록하고 적용할 물리 틱을 정한다. 화면 프레임에만 저장된 짧은 입력을 물리 틱이 놓치지 않게 한다.
2. 정해진 순서로 점프 승인, 속도 변경, 이동·충돌을 처리한다. 같은 입력이라도 접지 갱신 전후의 승인 순서가 다르면 결과가 달라진다.
3. 표시 시점에는 이전·현재 물리 상태를 읽는다. 필요하면 표시 위치만 보간하며, 보간 위치를 다음 충돌의 시작점에 다시 넣지 않는다.
4. 순간이동·리스폰은 이전 표시 상태도 초기화해 두 위치 사이를 잘못 그리지 않게 한다.

고정 틱은 재현 조건 하나다. 동일 결과에는 같은 초기 상태, 입력 배치, 갱신 순서도 필요하다. 물리 보간은 틱 사이의 움직임을 부드럽게 보이게 하지만 표시 지연을 추가할 수 있다. 물리 간격을 줄이면 초당 계산 횟수가 늘어난다. [Godot 물리 틱과 보간](https://docs.godotengine.org/en/stable/tutorials/physics/interpolation/physics_interpolation_introduction.html)

## 비교할 조건

표시 30/60/144 FPS를 바꾸는 비교에서는 물리 간격과 입력 기록을 고정한다. 물리 간격 1/30·1/60·1/120초 비교에서는 일정 중력 기준과 최고점·착지 시점을 비교한다. 버튼 해제는 상승·정점·하강을 나눠 확인한다. 높은 낙하 속도에서 생기는 충돌 누락은 [터널링](../collision-tunneling/analysis.md)의 별도 문제다.

Nintendo 설명서가 확인해 주는 것은 짧게 누르기와 길게 누르기의 조작 차이다. 그 결과만으로 속도 절단식, 작품별 상수, 역사적 최초성을 확정할 수 없다.
