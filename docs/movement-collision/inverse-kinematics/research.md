# 발 IK 리서치

[상세 분석](analysis.md) · [그룹 요약](../README.md)

수집 ID는 `inverse-kinematics`다. 영상 근거는 2026-09-22의 대표 화면·자막·OCR 분석이며, 2026-09-26에 대조한 공식 솔버 문서의 범위는 아래 표에 있다.

## 원자료의 구체 근거

[계단과 역운동학 영상](https://www.youtube.com/watch?v=0rjhNtdmgVI&t=27s)의 기존 분석은 00:27 발 목표에 따른 관절 변경, 00:45 여러 가능한 무릎 위치, 00:57 다관절 전후 조정 도식을 기록한다. 이번에 원영상 전체나 원작 보행 솔버를 실행한 것은 아니다.

목표가 사슬보다 멀면 도달할 수 없으며, 두 뼈 길이 차이보다 가까운 목표도 불가능하다. 뼈 길이·거리 조건과 무릎 원의 식은 삼각형 기하에서 직접 도출했다. 원작 코드의 식이라는 주장은 하지 않는다.

## 공식 자료와 해석

| 자료 | 확인한 위치 | 채택·제한 |
| --- | --- | --- |
| [Epic IK Rig Solvers](https://dev.epicgames.com/documentation/en-us/unreal-engine/ik-rig-solvers-in-unreal-engine) | 09-26 본문 열람, 페이지 표기 UE 5.8: `Limb IK`, `Full Body IK`, 각 `Settings`, `Pole Solver` | 단일 사지와 다중 목표 솔버, 관절 한계·강성·선호 각도를 구분한다. 반복 증가에는 CPU 대가가 있으며 Limb IK 추가 설정은 3본보다 긴 사슬에만 적용된다. |
| [Epic Control Rig Full-Body IK](https://dev.epicgames.com/documentation/unreal-engine/control-rig-full-body-ik-in-unreal-engine) | 09-26 본문 열람, 페이지 표기 UE 5.8: 개요·Root/Effectors 설정·`Bone Settings` | Position Based IK를 사용한 전신 보정의 사례다. 본문 대조를 엔진 실행·설정 재현 결과로 바꾸지 않는다. |

영상의 전후 조정 도식은 FABRIK 계열 설명과 연결할 후보지만, 그림만으로 사용한 라이브러리나 정확한 솔버를 단정하지 않는다. IK의 정의를 특정 반복 순서로 축소하지 않는다.

## 원인과 적용 판단

발 IK와 몸의 이동 충돌을 별도로 설명한다. 다리 자세를 맞추는 것과 몸의 계단 오르기 규칙은 필요한 상태가 다르다. 폴 퇴화 처리·접지 가중치·발판 상대 좌표·골반 보정 순서는 교육용 실험의 구현 선택지이며 영상에서 확인한 원작 구현이 아니다.

## 남은 질문

보행 실험을 선정할 때 리그 길이와 관절 한계, 지면 조회 범위, 접지 발 고정·해제 시점을 결정해야 한다. 반복 수에 따른 실제 CPU 비용과 보행 자연스러움은 미측정이다. 3D 수식의 특이점과 지면 목표 오차를 눈으로 확인하는 설계부터 시작할 수 있다.

원영상 프레임과 엔진 문서의 리그 이미지를 복제하지 않는다. 두 뼈·목표·폴의 도식은 자체 제작 대상으로 둔다.
