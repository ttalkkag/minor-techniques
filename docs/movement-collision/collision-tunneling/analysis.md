# 고속 물체의 충돌 누락

[그룹 요약](../README.md) · [리서치](research.md) · [실험 설계와 조작](experiment.md)

원자료: `collision-tunneling`. 정지한 벽을 향한 직선 운동의 계산식과 예를 이 문서에 제시한다. [실험 명세](experiment.md)는 이 모델의 조절값과 관찰 순서를 정의한다.

## 시작과 끝이 안전해도 중간은 안전하지 않다

위치 검사 A는 고정 시간 간격마다 탄환의 현재 도형이 벽과 겹치는지 확인한다. 검사 사이에 벽의 양쪽으로 이동하면 두 위치에서는 겹치지 않아도 경로 중간에는 충돌이 있었다. 이것이 터널링이다. 화면을 더 자주 그리는 것만으로 물리 검사 위치가 늘어나지는 않는다.

이 실험에서는 벽 중심 `w`, 두께 `b`, 탄환 반지름 `r`, 수평 중심 위치 `x`만 계산한다. 탄환이 벽의 평평한 면을 정면으로 통과하며 높이가 변하지 않는다. 중심이 다음 구간에 들어가면 접촉이다.

```text
L = w - b/2 - r
R = w + b/2 + r
접촉 = L ≤ x ≤ R
```

구의 크기를 없애는 대신 벽을 반지름만큼 확장한 셈이다. 일반적인 구–상자 모서리 충돌 전체를 이 1차원 식으로 판단하는 것은 아니다.

## 기본 조건을 계산한다

기본값은 `x0=-5 m`, `v=90 m/s`, `h=0.1 s`, `w=0`, `b=0.3 m`, `r=0.16 m`다. 접촉 구간은 `[-0.31, 0.31] m`, 한 스텝 이동은 `9 m`이므로 다음 위치는 `4 m`다. 시작점과 끝점 모두 구간 밖이다.

위치 검사 A는 끝점 4m에서 겹침이 없어 누락한다. 경로 검사 B는 -5m에서 4m로 가는 선분이 접촉 구간에 처음 들어오는 위치를 구한다.

```text
dx = x1 - x0
오른쪽 이동: 접촉 중심 xc = L
왼쪽 이동:   접촉 중심 xc = R
스텝 내 비율 u = (xc - x0) / dx
최초 접촉 시각 = 스텝 시작 시각 + u × h
```

시작점이 이미 구간 안이면 즉시 접촉(`u=0`)이다. 그 밖에서 이동이 없으면 접촉하지 않는다. 움직임이 있으면 `0≤u≤1`인 경우만 이번 스텝의 접촉이다. 수학 모델은 닫힌 경계를 사용하며, 부동소수점으로 구현할 때는 단위·규모에 맞는 경계 허용값을 별도로 정한다.

기본 예에서는 `u=4.69/9`, 접촉 시각은 `4.69/90 ≈ 0.052111 s`, 중심은 `-0.31 m`다. 벽의 실제 접촉 면은 `-0.15 m`이므로 중심 위치와 표면 접촉 위치를 구분한다.

## 해결 선택과 조건

| 방법 | 바뀌는 것 | 대가·제한 |
| --- | --- | --- |
| 물리 간격 감소 | 같은 경로에 검사 위치가 더 생김 | 초당 검사·적분이 늘고, 임의의 고속/얇은 형상까지 보장하지 않음 |
| 벽·판정 영역 확대 | 겹침 구간이 넓어짐 | 실제 지형·판정 감각이 바뀜 |
| 선형 sweep | 스텝 사이의 최초 접촉을 계산 | 지원 형상·상대 운동·충돌 후 재검사 처리가 필요 |
| Speculative CCD | 미래 후보 영역과 접촉 제약을 예측 | 오충돌·누락 가능성, 선택 엔진의 조건 확인 필요 |

현재의 1차원 일정 속도 모델에서 검사 간격 거리 `|v|h`가 접촉 구간 폭 `b+2r`보다 작거나 같으면, 구간을 완전히 지나가는 동안 적어도 한 샘플이 포함된다. 반대로 그보다 크면 시작 위치에 따라 성공과 실패가 달라진다. 따라서 큰 이동 거리 하나만으로 모든 경우의 실패를 단정하지 않는다.

120 Hz 예시는 스텝 거리 `0.75 m`, 구간 폭 `0.62 m`여도 시작 위치가 맞아 A가 `0.25 m`, `7/120≈0.058333 s`에서 접촉한다. B의 최초 접촉은 그대로다. 120 Hz가 모든 시작 위치에 충분하다는 결론은 아니다.

## 실제 CCD와 연결되는 한계

Unity의 선형 sweep 설명은 이동 방향의 최초 접촉과 충돌 후 하위 스텝을 다룬다. 회전축에 고정된 핀볼 플리퍼처럼 선형 이동 없이 회전만 하는 사례는 제한이 있다. [Unity Sweep-based CCD](https://docs.unity3d.com/6000.0/Documentation/Manual/sweep-based-ccd.html)

Speculative CCD는 각운동도 후보 확장에 반영하지만 부정확한 접촉 법선으로 물체가 엉뚱하게 튀거나, 충돌 해소 중 예측 영역 밖으로 가서 누락될 수 있다. 이 방법은 현재 실험 명세의 비교 대상에 포함하지 않는다. [Unity Speculative CCD](https://docs.unity3d.com/6000.0/Documentation/Manual/speculative-ccd.html)

실험의 검사 횟수는 함수 호출 수다. A·B 한 번의 실행 비용이 같다는 뜻이 아니다. 3D와 2D는 같은 결과의 표시 방식이며, 회전·가속·반사·마찰·움직이는 벽과 일반 접촉 해소는 계산하지 않는다.
