# 온라인 판정·롤백·저장과 복원

사격 화면, 서버의 판정, 저장된 게임 상태는 서로 다른 시점의 정보를 담는다. 무엇을 기준으로 판정하고 어느 상태까지 복원하는지를 정하면 네트워크 지연과 저장 실패를 이해하기 쉬워진다.

지연·예측·저장 중단 조건을 바꾸며 판정과 복원 결과를 비교한다. 원작 서버·저장 포맷과 자체 계산 예의 차이는 각 리서치에 구분했다.

## 통합 기준

히트스캔과 지연 보상은 공간의 출발점과 판정 시각이라는 다른 문제다. 롤백은 과거 충돌체 조회에 그치지 않고 게임 규칙을 입력 이력으로 다시 실행하므로 별도 이슈로 유지했다.

파일 저장과 패스워드 저장은 상태 직렬화를 공유한다. 파일 저장은 중단·호환성·동시 요청을, 패스워드는 용량·오타·복원 범위를 중심으로 나눴다. 상세 분석의 수치와 포맷은 원작 실측과 구분한 교육용 예제다.
