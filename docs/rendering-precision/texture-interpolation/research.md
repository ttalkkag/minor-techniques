## 자료와 열람 범위

수집 ID는 `ps1-texture-warping`이다. 아래 Sony 명세를 대상으로 아핀 보간, 분할 정점의 재투영, 정점 흔들림과의 차이를 조사했다. 영상 분석이 아닌 웹 문헌 조사 항목이다.

2026-09-25에 아래 Sony 공개 보관본의 해당 페이지를 대조했다. 바닥 기울기·거리·보간·분할·해상도를 독립적으로 바꾸는 비교 조건을 정리했으며, 이 비교 실험을 실제로 실행한 것은 아니다.

## 보간과 정점 정밀도의 구분

면 분할로 모든 흔들림을 해결할 수는 없다. 텍스처 보간은 이 문서에서, SXY0 화면 좌표 정밀도는 [별도 리서치](../screen-coordinate-precision/research.md)에서 다룬다. 하나의 화면 인상이 두 원인에서 올 수 있기 때문이다.

상세 분석의 무게식과 `0.5 → 0.2` 예제는 원근 보간 원리를 풀어 쓴 자체 설명이다. Sony 게임의 수치나 실측값이 아니다. 깊이가 같은 대조군과 잘못된 화면 공간 분할의 경우를 더해, 왜 해법이 작동하는지와 작동하지 않는지를 드러냈다.

## 남아 있는 질문

- 특정 PS1 게임이 어떤 조건으로 면을 분할했는지는 해당 게임 구현 또는 제작 기록이 추가로 필요하다.
- 분할 전후 실제 영상 오차와 프레임 시간은 아직 측정하지 않았다.
- UV 보간과 정점 양자화를 각각 켠 네 조합에서 현상이 독립적으로 보이는지는 웹 구현 후 확인해야 한다.
