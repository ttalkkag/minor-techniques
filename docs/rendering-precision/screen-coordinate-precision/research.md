# 화면 정점 정밀도 리서치

[상세 분석](analysis.md) · [그룹 요약](../README.md)

## 자료와 열람 범위

수집 ID는 `ps1-texture-warping`이다. 아래 Sony 명세를 대상으로 화면 좌표의 저장 형식과 정점 양자화가 텍스처 보간과 다른 단계라는 점을 조사했다. 영상 분석이 아닌 웹 문헌 조사 항목이다.

원근 보간과 정점 양자화를 별개 원인으로 구분한다. 2026-09-25에 아래 Sony PDF의 118·134쪽을 대조했으며, 수 형식 설명은 인쇄 쪽수 6-4를 기준으로 삼았다. 콘솔 실행은 하지 않았다.

## 명세에서 확인한 범위

| 자료와 위치 | 근거 | 채택 범위 |
| --- | --- | --- |
| [Sony, Inline Programming Reference](https://psx.arthus.net/sdk/Psy-Q/DOCS/Devrefs/Inlinref.pdf#page=118), 인쇄 5-34쪽 / PDF 118쪽, `GTE Register Specification`, Data #12 `SXY0` | SX0·SY0 화면 좌표 필드에 `(1.15.0)` 명시 | 투영 후 화면 좌표의 소수부가 없는 형식임을 확인 |
| [같은 문서](https://psx.arthus.net/sdk/Psy-Q/DOCS/Devrefs/Inlinref.pdf#page=134), 인쇄 6-4쪽 / PDF 134쪽, `GTE Commands Reference / Explanations`, `(a.b.c)` | 부호·정수·소수 비트의 표기 정의 | 형식의 마지막 숫자 0을 소수부 0비트로 해석 |

작성 주체는 Sony지만 링크는 현재 공식 배포처가 아닌 역사 문서 보관본이다. 레지스터 표 하나는 모든 GTE 연산의 반올림·포화 규칙이나 GPU의 경계 픽셀 선택을 설명하지 않는다. “PS1은 고정소수점이라 모든 화면이 흔들린다”는 넓은 결론으로 확대하지 않는다.

## 명세 위치와 자체 모델의 구분

수 형식 설명은 인쇄 **6-4쪽 / PDF 134쪽**, SXY0 주소와 형식은 인쇄 **5-34쪽 / PDF 118쪽**에 있다. 위 링크는 실제 PDF 페이지 번호를 사용한다.

상세 분석의 `floor` 격자 예제는 규칙을 먼저 정의한 자체 설명이다. 실제 명령의 결과를 확인하지 않은 채 이를 PS1의 정확한 양자화 규칙으로 소개하지 않는다. 텍스처 보간 변경으로 정점 위치가 복원되지 않는 이유를 처리 단계로 나눠 설명했다.

## 남아 있는 질문

- 음수·화면 가장자리·포화 범위에서 어느 명령이 어떤 결과를 내는지 명령 본문과 실기 결과를 추가로 대조해야 한다.
- 교육용 양자화와 실제 PS1 결과의 차이는 아직 수치화하지 않았다.
- 별도 저해상도 렌더링, 디더링, 정렬 문제를 추가할 때 이 정점 스위치와 어떻게 독립적으로 보여줄지는 후속 설계 대상이다.
