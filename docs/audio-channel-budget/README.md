# 게임기 음원 채널 제약

효과음이 재생될 때 배경음악의 특정 악기가 사라지는 현상을 다룬다. 제한된 음원 채널을 어떤 소리에 배정할지와 음악을 어떤 데이터로 저장할지를 비교한다.

[전체 목차](../README.md) · [상세 분석](analysis.md) · [리서치](research.md)

## 원인과 해결

하드웨어 음원 채널을 음악이 사용 중인데 효과음도 같은 채널을 요구하면 두 소리를 독립적으로 재생할 자리가 부족하다. 이 채널 수는 좌우 스피커 출력 수와 다른 개념이다.

효과음 요청을 거부하거나 음악·기존 효과음을 선점하는 정책을 비교한다. 음악의 곡 시계를 계속 진행하는 모형에서는 효과음 종료 후 현재 곡 위치에 맞춰 복귀한다. 소프트웨어 합산으로 더 많은 소리를 표현할 수도 있지만 계산·믹싱 비용이 추가된다.

## 저장 방식의 제약

음표 명령과 공유 악기 샘플을 저장하는 방식은 완성된 PCM을 저장하는 방식과 용량·재생 비용이 다르다. 시퀀스 명령만 세지 않고 악기 데이터까지 포함해 비교한다. 샘플 재생 속도를 바꾸면 음높이와 길이가 함께 달라지는 점도 확인한다.

## 조절하며 비교할 항목

- 동시 채널 수, 효과음 우선순위·길이에 따른 채널 소유자와 빠지는 악기.
- 효과음 종료 후 음악으로 복귀하는 시점.
- 시퀀스·악기 데이터와 PCM의 저장 크기, 샘플 재생률에 따른 길이 변화.

채널 배분과 저장 계산은 교육용 모형이며 특정 게임의 드라이버 정책이나 정확한 칩 에뮬레이션을 재현한 것은 아니다.
