# 게임 AI의 관측·행동·보상

게임 AI가 오래된 화면으로 행동하거나, 명령 전송을 목표 달성으로 착각하거나, 보상만 높이는 플레이를 하는 원인을 다룬다. 실제 게임 상태와 AI가 받은 정보, 실행 결과와 목표를 나누어 비교한다.

## 이슈별 요약과 상세 문서

| 이슈 | 원인 | 해결 방향과 대가 | 상세 |
| --- | --- | --- | --- |
| 끝난 목표를 반복하거나 잘못된 위치로 이동함 | 관측 지연, 맵 전환, 행동 결과와 목표 상태의 불일치 | 관측 시각·맵·완료 조건을 기록하고 짧은 행동 뒤 다시 확인. 관측·호출 비용 증가 | [분석](observation-action-loop/analysis.md) · [리서치](observation-action-loop/research.md) |

## 관측과 실행 결과

포켓몬의 목표 반복, Minecraft의 부분 건축과 행동·대사 불일치는 계획을 보냈다는 사실만으로 실제 결과를 알 수 없다는 문제를 보여 준다. `관측 → 한정된 행동 → 새 관측 → 완료 조건 확인`을 반복하고, 대사와 다음 계획은 확인된 결과를 사용한다. 직접 월드를 편집하는 건축과 이동·채집이 필요한 생존 플레이는 비용 조건이 다르다.

실험에서는 2D 격자의 실제 상태와 관측 상태를 나란히 놓고 관측 지연·행동 길이를 조절한다. 부분 건축 실패에서는 요청한 블록과 실제 블록의 차이를 보여 준다. 이러한 모형은 원작 에이전트의 성능 재현과 구분한다.

## 보상과 성공 조건

이동할 때마다 점수를 주면 왕복만 반복해도 보상이 쌓일 수 있다. 목표 도달·죽음·외부 중단을 구분하고, 보상식이 의도한 플레이를 만드는지 반례로 확인한다. Double DQN의 행동 선택·가치 평가 분리는 [상세 분석](reward-design/analysis.md)에 설명했다.

실험에서는 진행 보상·사망 비용·도착 보상·남은 시간을 바꾸면서 선택 경로와 클리어율을 비교한다. 단순 격자 모형은 보상 설계의 원리를 설명하며, 영상 속 신경망 학습이나 성공률을 재현한 결과는 아니다.
