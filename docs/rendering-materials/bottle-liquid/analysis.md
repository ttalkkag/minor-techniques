# 병의 수면 근사와 부피 보존의 차이

[그룹 요약](../README.md) · [조사 근거](research.md)

병을 흔들면 액체가 반응하는 것처럼 보이게 할 수 있다. 액체의 모든 내부 흐름을 계산하지 않고 수면 경계와 시간 변화만 정하는 것이 여기서 다룰 자체 근사다. Half-Life: Alyx의 공식 기록은 액체 표현 추가와 셰이더 수정까지 확인해 주며 아래 모델이 Valve 코드라는 근거는 아니다.

## 병과 수면이 다른 좌표계를 쓰는 과정

병 로컬 점 `q`를 월드로 옮기는 회전 `R`, 위치 `p`가 있고 월드 위 방향이 `u`라면 점의 세계 높이는 `u·(Rq+p)`다. 세계 수면 높이 `h_world` 아래의 내부 점만 액체 영역으로 택하는 단순 조건은 다음과 같다.

```text
n_local = Rᵀu
h_local = h_world - u·p
액체 영역: 병 내부이면서 n_local·q ≤ h_local
```

위 식은 `R`이 순수 회전인 자체 모델이다. 비균일 스케일을 섞으면 같은 변환을 그대로 적용하지 않는다. 병에 고정된 로컬 수면은 병과 함께 돌아가지만 세계 높이 기준 수면은 병이 회전해도 중력 방향을 유지한다. 먼저 이 차이만 보여 주면 흔들림 장식을 넣기 전 원리를 관찰할 수 있다.

## 출렁임을 더하는 설명용 모델

수면 기울기 `θ`에 대해 `θ″+2ζωθ′+ω²θ=k·a_input` 같은 감쇠 모델을 선택할 수 있다. `ω>0`, `ζ>0`이고 외력이 0으로 유지될 때 기울기는 0으로 수렴한다. `0<ζ<1`이면 감쇠 진동하며 같은 `ω`에서 작은 `ζ`는 진폭 감쇠를 늦춘다. `ζ=0`이면 진동이 저절로 줄지 않고, `ζ≥1`에서는 자유 응답이 진동형이 아니므로 “감쇠를 키울수록 항상 더 빨리 돌아온다”라고 설명하지 않는다. `a_input`의 단위·부호와 회전/이동 입력 중 무엇을 쓰는지는 명시해야 한다. 이 식은 두세 개의 상태값으로 시각 반응을 만드는 설계 선택이며 압력·속도장을 푸는 유체 솔버가 아니다.

위치 경계를 잘라내는 것만으로 수면의 윗면이 자동 생성되는 것도 아니다. 단면을 채우는 표현, 병의 외형·액체 경계·반사 정보를 어떻게 그릴지 별도로 정해야 한다.

## 채움 높이와 액체 양

똑바로 선 병의 수평 단면적을 `A(y)`, 내부 바닥 높이를 `y_min`이라 하면 높이 `h` 아래의 양은 `V(h)=∫_(y_min)^h A(y)dy`다. `h`는 병 내부의 유효 높이 범위로 제한하고, 바닥 이하는 0, 병의 최상단 이상은 전체 내부 부피로 둔다. 바닥을 0으로 둔 반지름 1인 원통을 높이 0.5까지 채우면 자체 기하 예에서 `V=0.5π`지만, 같은 높이에서도 반지름 0.5 원통이면 `V=0.125π`다. 높이 설정만 같다고 같은 양이 아니다.

기울어진 병의 일반 형상에서는 수면 아래 내부 부피로 다시 계산해야 한다. 일정 양을 목표로 한다면 수면 높이를 움직여 목표 부피를 맞추는 과정이 필요하며, 샘플 격자로 근사하면 격자 해상도 오차도 남는다. 매 프레임 고정 높이를 쓰는 모드와 부피를 맞추려는 모드를 구분한다.

## 해결 절차와 깨지는 조건

1. 닫힌 단순 병과 정적 수면부터 시작하고 병 내부·수면 평면을 표시한다.
2. 같은 움직임을 병 고정 수면과 세계 기준 수면에 입력한다.
3. 기울기·감쇠를 추가하되 카메라 조작은 병에 가해지는 입력에서 제외한다.
4. 채움 높이·병 형상·급회전을 바꾸며 경계와 예상 부피를 비교한다.

열린 병, 뒤집힘, 흘러나옴, 큰 파도·분리된 액체는 이 단순 모델의 범위를 벗어난다. 채움 영역·감쇠만으로 실제 유체 대비 절감률을 주장할 수도 없다. [Valve Update 1.4](https://steamcommunity.com/games/546560/announcements/detail/2229791404478061089)의 현상을 학습 출발점으로 쓰되, 자체 모델의 실패를 원작 버그라고 표시하지 않는다.
