## 조사 범위

수집 ID `interior-mapping`의 원영상과 저자 논문을 비교한다. 아래 장면 시점은 2026-09-22 대표 화면 분석에 대응한다. 2026-09-23 통합 검토에 이어 2026-09-25 원논문 본문을 대조해 가구 평면 확장과 한계를 보존했다. 원영상 전체를 다시 재생한 기록은 아니다.

## 자료 간 차이와 채택 판단

- 평면 사진과 달리 시선에 따라 내부 교차 위치가 바뀐다는 설명은 채택했다.
- 원논문 §2.4의 가구 평면은 실제 메시 없이 방 가운데 세운 것처럼 표현하는 확장이다. “가구는 모두 뒷벽에 붙어야 함”으로 축소하지 않았다.
- 논문이 정확히 수평인 광선의 0 나눗셈으로 생기는 아티팩트를 드물다고 설명해도 자체 교육 모델에서는 0 방향 성분을 명시적으로 처리한다. 이는 구현 선택이다.
- Spider-Man의 모든 방·창문이 동일 구현이라는 주장은 원자료도 개발사 코드로 확인하지 못했다. 분석의 단일 박스는 특정 게임의 역공학 결과가 아니다.
- GPU Resident Drawer는 실제 기하와 비교할 엔진별 후속 후보이며 이번 도입 권고로 채택하지 않았다.

## 남은 질문

실내 전환 위치, 반복 방의 자산 관리, 반사와의 합성, 픽셀 점유율별 비용은 미결정이다. 원논문과 영상의 그림은 복제하지 않았으며 자체 광선·박스 도식으로 설명할 수 있다. 대표 화면 분석과 논문 텍스트 열람은 원작 셰이더 실행 검증을 대신하지 않는다.
