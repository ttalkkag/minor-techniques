# 상황에 따른 음악 전환

탐험에서 전투로 바뀔 때 음악이 박자를 놓치거나, 전투가 끝난 뒤 예약된 전투 음악이 재생되는 문제를 다룬다. 게임 이벤트 시각과 음악의 전환 가능 시각을 구분하는 것이 핵심이다.

[전체 목차](../README.md) · [상세 분석](analysis.md) · [리서치](research.md)

## 원인과 해결

게임 프레임과 오디오 재생 시계는 다르다. 여러 재생 명령을 같은 프레임에 보내도 원하는 박자에 맞지 않을 수 있으며, 정확한 시각에 시작하더라도 앞뒤 음악 구절이 연결되지 않으면 부자연스럽다.

공유 오디오 시간축에서 다음 박자·마디에 전환을 예약하고, 음악 구성에 따라 악기 층을 추가하거나 구간·브리지를 바꾼다. 게임 상태가 다시 바뀌면 남은 예약을 취소하거나 교체한다. 음악적 연결을 기다리는 만큼 반응이 늦어지는 대가가 있다.

## 조절하며 비교할 항목

- 전투 진입 시각, BPM, 예약 여유에 따른 실제 전환 시각.
- 악기 층 추가와 구간 교체의 차이.
- 짧은 상태 전환·연타에서 예약을 유지하거나 취소한 결과.

박자 커서와 이벤트·예약·실행 시각을 함께 표시하면 지연의 원인을 비교할 수 있다. 이 모형은 원작 음악의 청취 품질을 재현하는 것과 구분한다.
