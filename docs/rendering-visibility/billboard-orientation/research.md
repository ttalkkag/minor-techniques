## 질문과 자료 열람 범위

질문은 “카메라를 향한다는 세 가지 설명이 같은가, 상공에서는 왜 깨지는가”이다. 수집 ID는 `billboards`이며 원영상과 주요 장면은 아래 표에 있다. 2026-09-22 대표 화면 검토, 2026-09-23 통합 검토를 거쳐 2026-09-25 공개 API의 관련 절을 재열람했다. 2026-09-26에는 Godot 4.6의 모드 설명과 Unity 6.0의 블렌딩 제약을 다시 검색·대조했다. 영상 전체 재생과 엔진 실행은 수행하지 않았다.

## 원자료를 어떻게 반영했나

- 시점 지향·화면 평행·세로축 고정의 세 정렬 기준은 유지했다. 분석 문서에서는 실제 정점 위치를 구성하는 기저와 영벡터 예제를 더했다.
- 상공·직교·반사 시점에서 기준이 달라지는 문제를 실패 조건으로 구체화했다. 특히 회전 규칙과 알파 정렬 오류는 원인이 달라 구분했다.
- 단일 평면의 적은 기하량을 전체 렌더링 비용의 우위로 읽지 않는다. 중첩 비용은 잔디 문서로 연결했다.
- 기존 영상 검토는 대표 화면 대조 범위다. 이를 전체 프레임 정밀 검토나 구현 성공으로 확대하지 않는다.

## 보류한 선택과 추가 질문

다각도 임포스터의 실제 이미지 수·저장량·전환 오차와 근거리 메시 전환 거리는 아직 정하지 않았다. Godot의 축 설명은 문서로 확인했지만 해당 버전에서 직접 생성한 평면으로 실행하지 않았다. 자체 모델에서는 어떤 앞면 축을 쓸지 먼저 고정하고 상공 통과 전후의 방향 연속성을 확인해야 한다.

영상 캡처와 엔진 문서 그림은 이 문서에 복제하지 않았다. 향후 설명 그림은 자체 도식으로 만들고 외부 이미지를 사용한다면 별도로 이용 조건을 확인한다.
