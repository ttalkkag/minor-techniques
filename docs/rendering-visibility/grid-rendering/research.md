## 조사 질문과 범위

수집 ID `raycasting`의 고전 3D 도식을 Doom 구현 설명으로 사용할 수 있는지 검토했다. 2026-09-25 원영상 자막과 공개 Doom 코드의 아래 함수를 대조했다. 2026-09-23의 BSP 구분 교정을 유지하고 단순 투영식과 반례를 추가했다. 2026-09-26에는 공개 Doom 코드와 Lode의 격자 렌더러 설명을 다시 검색하고 본문을 대조했다. 원작 실행이나 영상 전체 재생은 하지 않았다.

## 자료를 통합하며 보존한 차이

“Doom도 동일 열별 격자 광선 렌더러”라는 해석은 위 표의 공개 코드의 자료구조와 맞지 않아 채택하지 않았다. 관측자 시야 검사와 렌더러가 선·공간이라는 개념을 공유해도 결과와 자료구조가 다르므로 독립 이슈로 둔다. 분석의 `F·H/z`와 전방 깊이 예제는 자체 기하 도출이다.

코드 링크는 `master`라 이후 줄 번호가 바뀔 수 있어 함수 이름으로 위치를 기록했다. 확인한 것은 현재 공개 파일의 해당 흐름이며 전체 엔진의 모든 표면·가림·텍스처 경로와 역사적 모든 출시판은 아니다.

## 남은 질문

격자 모서리 동률 처리, 투명 셀 통과, 카메라 내부 시작과 근접 절단 정책은 자체 렌더러를 선택할 때 정해야 한다. Wolfenstein과 Doom의 모든 차이, 원작별 실기 속도는 확인하지 않았다. 대표 화면 분석과 공개 코드의 정적 열람은 코드 실행 성공을 증명하지 않는다.
