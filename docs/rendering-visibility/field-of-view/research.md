## 채택·보정 판단

두 영상은 같은 발견 과정의 각도 계산과 차폐 계산을 설명하므로 하나로 통합했다. 레이캐스팅 영상의 천장 이동과 고전 렌더링은 결과가 공간 배치·화면 생성으로 달라 별도 이슈로 남겼다. 원자료의 cos(30°)≈0.87 사례는 각도 개념의 근거로 유지하되, 분석에는 정규화를 빼먹었을 때의 자체 수치 반례를 추가했다. 수평 시야에서는 표적 방향뿐 아니라 전방도 투영·정규화해야 하며, 수직 방향의 투영이 영벡터가 되는 조건을 별도로 명시했다.

“내적이 크면 보임”은 벽·거리·신체 부위·기억을 다루지 않는 단계 판정이다. 자동 자막에는 기술 용어 오인식과 중복 문장이 있으므로 원문 전체의 정확한 인용으로 쓰지 않았다. 대표 화면 대조와 자막 열람을 영상의 모든 프레임 확인으로 확대하지 않는다.

## 보류한 기능

Epic AI Perception은 발견/유지/망각을 분리할 후속 후보이다. 이번에는 해당 API 버전을 다시 열람하거나 사용하지 않았고, 단순 내적 실험의 필수 의존성으로 채택하지 않는다. 여러 신체 점 중 어떤 규칙을 사용할지, 시작점 내부에서 실패로 처리할지 보정할지, 재발견 지연을 얼마로 둘지는 아직 결정하지 않았다.

00:47 이후 조명 응용은 [노멀맵 리서치](../../rendering-materials/normal-mapping/research.md)와 연결한다. 코사인 기하항과 Lambert BRDF를 분리한 기존 교정을 유지한다.
